What’s New in v5

100% HTML Prototype
1
Per-Collection “Add Record Form Style” in Collection Settings (⚙️)

Inside ⚙️ Collection Settings, there is now an Add Record Form Style dropdown with two options: Popup Card (Sheet) or Complete New Screen (Full Page). Whatever you choose for that collection is automatically used whenever you tap ＋ Add on Home (grape cluster) or inside the Collection!

2
“Field Shown Beside Title” Strictly Inside Collection Settings (⚙️)

Completely removed from the Collection list and filter bar. In ⚙️ Collection Settings, use the Field Shown Beside Title (Compact View) dropdown to pick which field (e.g., Product Cost, Expiration Date, Brand) appears beside the title when viewing the collection in Compact mode.

3
All Sexy Dropdowns inside Collection Settings

Collection Settings now houses three cohesive custom dropdowns: (1) Collection Theme Color, (2) Field Shown Beside Title (Compact View), and (3) Add Record Form Style (Popup Card vs. Full Screen), plus the 4-tab Icon Picker and Schema Fields list.
